# 🛡️ Mund Global – Premium Insurance Broking Website

A modern, fully responsive **insurance broking website** designed with a premium UI/UX experience.  
Built using **HTML, CSS, and JavaScript**, this project showcases professional design, animations, and real-world business layout.

--

## 🚀 Live Features

- ✅ Premium hero section with call-to-action
- 📊 Animated statistics counter
- 🧩 Insurance categories grid
- 🤝 Trusted insurance partners carousel
- 🗣️ Client testimonials
- 📩 Interactive contact & callback form
- 🍔 Responsive hamburger navigation
- 🎨 Modern UI with smooth animations
- 💼 Developer credit system (toast + footer)
